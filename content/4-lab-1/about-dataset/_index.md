This deals with the publicly announced land price data of Seoul provided by Korea's public data portal.

The data is in CSV format and consists of the following columns:

- Unique Number
- Legal Dong Code
- Legal Dong Name
- Special District Code
- Special District Name
- Lot Number
- Base Year
- Base Month
- Publicly Announced Land Price
- Announcement Date
- Standard Lot Status
- Data Base Date
- Source City/Province/County Code

We will proceed with Lab-1 utilizing the publicly announced land price public data as described above.
