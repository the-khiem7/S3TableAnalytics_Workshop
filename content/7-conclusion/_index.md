Through this workshop, we conducted hands-on exercises on how to load CSV data into Apache Iceberg based on Amazon S3 and S3 Tables, and how to query and use it. The aspects covered in the workshop are fundamental for building a data lake, and you can expand your data analysis system based on this foundation. (Ultimately, the most important aspect of a data analysis system is the data itself.)

## Next steps

![Workshop diagram](/images/workshop/next-workshop-diagram.webp)

You can expand to the green box parts in the diagram above.

If you extend to the green parts, you will have a system that allows you to query the data stored in the data lake through various query engines, visualize it, and freely analyze data in an analytical UI environment.

By utilizing the following AWS Analytics services, you can easily build such a system:

- [AWS Glue](https://aws.amazon.com/glue/)
- [Amazon Athena](https://aws.amazon.com/athena/)
- [Amazon EMR](https://aws.amazon.com/emr/)
- [Amazon Sagemaker](https://aws.amazon.com/sagemaker/)
- [Amazon Quicksight](https://aws.amazon.com/quicksight/)
