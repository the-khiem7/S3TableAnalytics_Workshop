{{% notice info %}}
This page provides guidance on prerequisites before starting the lab when attending an event hosted by AWS.
{{% /notice %}}

1. If you are participating in a hosted AWS event, the Workshop Studio Portal will be used. To sign up, click [here](https://catalog.us-east-1.prod.workshops.aws/join). Then click the Email One-Time Password (OTP) button.

![Sign-in](/images/workshop/sign_in.webp)

2. Enter your email account and click the Send passcode button.

![Passcode](/images/workshop/send_passcode.webp)

3. In your email inbox, select the "Your one-time passcode" email and copy the password. Paste the copied password and then press the Sign in button.

![Passcode](/images/workshop/one_time_email_passcode.webp)

4. When the event access code screen appears, enter the 12-digit Event Access code you received from the event organizer. Click the Next Button to continue.

![Access](/images/workshop/enter_event_access_code.webp)

5. On the next screen, check the Accept Terms & Conditions box. Click the Join event button to proceed to the next step.

![Access](/images/workshop/terms_and_conditions.webp)

6. Select the Open AWS Console button on the left side of the screen to access the AWS Management Console page.

![Access](/images/workshop/console_access.webp)

If you have completed all the steps above, you are ready to start the lab.
